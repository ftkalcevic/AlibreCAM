AlibreCAM Help

A CAM add-on for Alibre Design assemblies.

AlibreCAM adds a CAM tab to the Design Explorer of an assembly. In it you build a sequence of operations that machine the assembly's parts, generate a toolpath for each, see the toolpaths in the view, and post them as G-code for your machine. Toolpaths are 3+2 indexed: each Set Origin step can tilt or move the origin, and operations run under the origin above them.

The job is kept in a .cam file beside the assembly, with the same name. It's saved only when you press Save, and you're warned about unsaved changes when the assembly closes. All lengths are in millimetres, and Z is measured along the active origin's Z axis, pointing out of the material.

Press ? on the CAM tab's toolbar, or at the bottom left of a dialog, to open this page at the section for it.

CAM tab

The CAM tab is the add-on's home. Open it from the CAM command in an assembly. It holds a toolbar, the CAM tree, a status area, and the Refresh view and Save buttons. Toolpaths and origins are drawn in the view while the tab has focus, and hidden when it doesn't.

Toolbar

Draw over model
When pushed in, toolpaths and origins are drawn in front of the model, so you can always see them. When out, the model can hide them. On by default, and not saved.
Show toolpaths
Shows or hides every toolpath. Boundaries and picked feature outlines stay visible. On by default, and not saved.
? (Help)
Opens this page at the CAM tab section.
Settings (gear)
Opens the Settings dialog.

Tree

The tree has a fixed Setup at the top and the Operations sequence below it. Operations run from top to bottom. Drag a step to reorder it.

Setup ▸ Machine
To be completed. Machine settings aren't built yet.
Setup ▸ Tools
The tools in the job's tool library. Click a tool to select it: new operations start with the selected tool. Double-click Tools or a tool to open the Tool Library.
Setup ▸ Stock
To be completed. Stock isn't built yet.
Operations
The ordered sequence of Set Origin steps, folders and operations. Right-click it to add steps, generate all toolpaths, or post.
Set Origin
Defines the origin (work coordinate frame) for the steps below it, up to the next Set Origin. The first one that isn't suppressed is the work zero for posting. Selecting one draws it in the view.
Folder
A group of operations, which can be generated or posted together. Folders don't nest. Use Rename to change a folder's name.
Operation
A machining operation: Drill, Hole Pocketing, Facing, Profiling or Pocketing. Double-click it, or use Edit, to open the Operation dialog. Selecting an operation draws its toolpath in bold and its picked geometry in orange.
Suppressed items
Shown grey, with their toolpaths drawn thin and grey. A suppressed Set Origin is skipped, and suppressed operations are left out of Generate and Post.

Right-click menus

Adds a Set Origin step and opens the Set Origin dialog.

Adds a folder to the Operations sequence.

Adds a Drill operation to a folder: drills holes at picked circles, hole faces and points.
Add Holes ▸ Hole Pocketing
Adds a Hole Pocketing operation: cuts round holes with an end mill on a helix and spiral.
Add 2 1/2 Axis ▸ Facing
Adds a Facing operation: cuts an area flat in levels.
Add 2 1/2 Axis ▸ Profiling
Adds a Profiling operation: cuts along a profile of edges, inside, outside or on it.
Add 2 1/2 Axis ▸ Pocketing
Adds a Pocketing operation: clears the area inside closed loops.
Edit
Opens the step's dialog.
Rename
Edits the item's name in place in the tree.
Duplicate
Adds a copy of the step below it.
Suppress
Turns the step off, or back on. See Suppressed items above.
Delete
Removes the step (a folder with its operations).

Calculates the toolpaths of the chosen operation, folder, or every operation. Problems are reported in the status area.
Post
Writes the toolpaths of a folder or every operation as a program for the machine, through the Post dialog. Every operation must have been generated first.

Status and buttons

Status
Messages from the last action, such as Generate's results and problems.

Draws the toolpaths and origin again. Use it after a native Alibre command, such as Measure, has ended the CAM display.
Save
Saves the job to its .cam file beside the assembly.

CAM View Size
The size of the CAM tab's text, buttons and toolbar icons. Small uses Windows' normal font and 16 pixel icons, Medium text 1.25 times as large and 24 pixel icons, and Large 1.5 times and 32 pixel icons.

Cancel
Closes the dialog without changing anything.

Tool Library

The tools a job can use. Tools are kept only in a library file, not in the job. The default library is %APPDATA%\AlibreCAM\tools.json, and a job can use another library instead. Changes are saved to the library file straight away.

Library
The library file this job uses.
Tool list
The library's tools, with their numbers, names, types and sizes. Double-click a tool to edit it.
Add

Edit

Copy
Adds a new tool starting as a copy of the chosen one.
Delete
Removes the chosen tool from the library. Operations that use it will report the tool as missing.
Other library
Chooses another library file for this job.
Use default library
Goes back to the default library for this job.
Close
Closes the dialog.

Tool

Flute count
The number of flutes (end mills).
Point angle (deg)
The drill's included point angle, such as 118. Used by the Drilling tab's Add drill tip to depth.

Set Origin

Defines an origin from picked geometry: its Z axis (the tool axis, pointing out of the material), its position, and its X direction. The steps below it, up to the next Set Origin, run in this origin. The origin is drawn with red, green and blue axes and its XY plane as an outline and grid.

Name
The step's name in the tree.
Plane (Z) Pick
Picks the geometry that gives Z. A flat face points Z out of the material, a cylindrical face gives its axis, a circular edge gives its axis and its centre, and a straight edge runs Z along it.
Position Pick
Picks an edge for the origin's position: the nearer end of a straight edge, or a circle's centre. Without one, the plane pick gives the position when it's an edge.
Position Clear
Removes the position pick.
X direction Pick
Picks a straight edge for X, projected onto the XY plane and pointing away from the end nearer where you clicked. Without one, X is the assembly's X projected onto the plane (or its Y, if X is too close to the tool axis).
X direction Clear
Removes the X direction pick.
Flip Z
Reverses the Z axis.
Turn X about Z
Turns X about Z in quarter turns.
Offset X, Y, Z
Moves the origin along its own axes, in millimetres, after everything else.
Prompt and result
What to pick next, and the resulting origin or why it can't be made.
OK
Saves the origin.
Cancel
Closes the dialog without changing the step.

Post

Writes the generated toolpaths as a program for a machine. Every point is measured from the work zero, the first Set Origin that isn't suppressed. Posts are plain text .post files in the add-on's posts folder, and your own in %APPDATA%\AlibreCAM\posts\ add to them or replace one with the same file name.

Posting
What's being posted: every operation, or a folder's.
Post
The post to use, such as LinuxCNC. The built-in APT CL data post is last. The dialog starts on the post used last time.
Output file
Where the program is written. It's suggested beside the .cam file, named after the assembly, with the post's extension.
Browse
Chooses the output file.
Post (button)
Writes the program.
Cancel
Closes the dialog without posting.

Operation dialog

The settings of one operation, on tabs. The dialog stays open while you work in the view, so you can pick geometry. Every operation has Features, Tool, Feeds & Speeds and Clearance tabs, followed by its own:

  • Drill: Drilling.
  • Hole Pocketing: Hole Pocketing.
  • Facing: Cut Levels, Entry/Exit, Facing.
  • Profiling: Cut Levels, Entry/Exit, Profiling.
  • Pocketing: Cut Levels, Entry/Exit, Pocketing.

Pressing ? opens the help for the tab that's showing.

Name
The operation's name in the tree.
Generate
Applies the dialog's settings to the job and generates this operation's toolpath, leaving the dialog open.
OK
Applies the settings and closes the dialog. Changing settings discards the old toolpath.
Cancel
Closes the dialog without changing the operation.

Features tab

The geometry the operation machines, in the order it's machined. Each operation takes its own kinds of geometry: Drill and Hole Pocketing take circles, arcs, hole faces and design points; Facing, Profiling and Pocketing take faces and edges, including spline curves. For the 2 1/2 axis operations only the geometry's position in the origin's XY plane matters: the heights come from the Cut Levels tab. Each face is an area of its own, and edges whose ends meet are grouped into one.

Feature list
Each feature's type, part, diameter, and X, Y and Z in the operation's origin. Drag rows to reorder them. Choosing rows selects them in the view. Press Delete to remove the chosen rows.
Select Features
Turns the view's selection into the list. The listed features start out selected; click or Ctrl+click in the view to add or remove features, and press Done when finished. New features are added at the end.
Delete
Removes the chosen rows.
Note
Says what this operation accepts, and any problem with the list.
Sort ▸ Order
How Sort orders the list: Minimum distance (from the first feature, always to the nearest one left), or Directional (zigzag rows, X first or Y first).
Sort ▸ Start corner
For Directional, the corner the rows start from: top left, top right, bottom left or bottom right.
Sort
Reorders the list now.

Tool tab

The tool the operation cuts with, chosen from the job's tool library. A new operation starts with the tool selected in the tree.

Tool list
Every tool in the library, with its T number, name and type. Choose one.
Tool details
The chosen tool's sizes, in its own unit. If the operation's tool is missing from the library, this says so.

In revolutions per minute.
Plunge

Approach

Cutting, including entry and exit leads and step-overs.

Clearance tab

The clearance plane: the height, along the origin's Z, that the tool moves across at between cuts. It must be above where cuts start.

Automatic
5 mm above the parts, for now.
Part max Z + distance
The distance above the highest point of the parts.
Stock max Z + distance
The distance above the top of the stock. Stock isn't built yet, so this fails for now.
Absolute Z value
A Z value in the operation's origin.

Cut Levels tab

The heights an area is cut at, for Facing, Profiling and Pocketing. The cut geometry's height is the highest point of all the selected features, unless you pick a top. The depth is split into rough levels, then finish levels.

At Top
The cut starts at the selected geometry's height and goes the total depth down.
At Bottom
The cut ends at the selected geometry's height, starting the total depth above it.
Pick Top
The cut starts at the Z in the box. Pick fills it with a picked item's Z in the operation's origin.
Total Cut Depth
How deep the cut is in all. Pick sets it to a picked item's distance from the cut geometry. A total of 0 cuts one pass at the top.
Rough Depth and Finish Depth
How the total is shared between roughing and finishing; they always add up to the total. The slider sets the rough share.
Rough Depth/Cut
The most each rough level cuts. The levels are spaced evenly. The slider sets it as a percentage of the rough depth.
Finish Depth/Cut
The most each finish level cuts, likewise.
Clear Island Tops
To be completed. Not used yet.
Use 3D Model to Detect Depth
To be completed. Not used yet.
Depth First
Each area, profile or pocket is cut to its full depth before the next.
Level First
Every area is cut at a level before going down to the next level.

Entry/Exit tab

How the tool moves into and out of each cut, for Facing, Profiling and Pocketing. A positive angle or radius puts the lead on the side away from the geometry, and a negative one on the other side. Leads run at the cut feed.

Entry Motions: None
The tool plunges straight down at the start of the cut.
Entry Motions: 2D Entry
The tool goes down beside the cut and leads in at the cut's level, as set in Engage Motion.
Entry Motions: Along 3D Path
The tool ramps down into the cut, starting in line with it, as set in 3D Path.
Engage Motion: Linear
A straight lead in of the Length, at the Angle from the cut's line (0 in line with it, 90 square to it, -180 to 180).
Engage Motion: Radial
A quarter circle lead in of the Radius, tangent to the cut.
Along Path Angle
The ramp's slope, more than 0 and under 90 degrees.
Along Path Height
How far above the cut the ramp starts. It must be below the clearance plane.
Exit Motions: None
The tool lifts straight up at the end of the cut.
Exit Motions: 2D Exit
The tool leads out at the cut's level, as set in Retract Motion, then lifts.
Retract Motion: Linear / Radial
Like Engage Motion, for leading out.
Apply entry/exit at each cut level
When on, every level's cuts have entries and exits. When off, only the first level's cuts have entries and only the last level's have exits; the rest plunge and lift straight.

Facing tab

How Facing clears its areas. Each area is cut at every level, from the Cut Start corner.

Cut Direction: Climb
Every pass cuts the same way, with the material on the cutter's right (clockwise spindle), lifting between passes. A spiral turns clockwise.
Cut Direction: Conventional
Every pass cuts the other way, lifting between passes. A spiral turns anticlockwise.
Cut Direction: Mixed
Passes zigzag backwards and forwards, stepping over square to the passes at whichever end reaches further out, without lifting.
Cut Angle
The passes' direction in degrees: 90 runs along the origin's X, 0 along its Y.
Step Distance
How far each pass moves over from the last, as a % of the tool diameter or a distance.
Arc step-overs
For Mixed with Linear, each step between passes is a half circle beyond the passes' ends.
Overtravel
How far the cutter centre goes past the boundary, as a % of the tool diameter or a distance. 0 stops the centre on the edge; 50% goes half the tool past it.
Cut Type: Linear
Straight passes along the cut angle.
Cut Type: Spiral
Rectangular loops around the area, from the outside in.
Cut Start
The corner the cut starts from, seen from the origin's +Z: Top Left, Top Right, Bottom Left or Bottom Right. For one-way Linear passes, it picks the side the passes start along, and the direction picks the end.

Profiling tab

How Profiling cuts along its profiles. Each group of joined edges, or each face's outline, is a profile; a profile that doesn't close is open, and its cut ends square to its ends.

Stock to Leave
Material left beside the profile, maybe for a finishing pass. Negative cuts into the profile.
Cut Direction
Climb keeps the profile on the cutter's right (clockwise spindle), Conventional on its left. Mixed runs the profile's own way.
Cut Start Side
Right or Left of the profile, seen from +Z, going the profile's way.
Use Outside/Inside for Closed Curves
When on, closed profiles are cut on their Outside or Inside instead of the start side.
Determine using 3D Model
To be completed. Not used yet.
Total Cut Width
The width cut beside the profile. 0 is a single pass. Wider, the passes start that far out and step in to the profile.
Step/Cut
The most each pass steps over, up to the total width. The slider sets it as a percentage of the width.
Use Tabs
Leaves tabs of material to hold the part.
Tab Height
How tall the tabs are, from the bottom of the cut.
Tab Length
How long each tab's material is along the profile.
Number of Tabs
The number of tabs, spaced evenly along the profile.
Distance between Tabs
One tab every distance along the profile.

Pocketing tab

How Pocketing clears the area inside each closed loop or face. Islands aren't left yet.

Stock to Leave
Material left on the pocket's walls. May be negative.
Offset Cuts
Loops following the wall, a stepover apart.
Linear Cuts
Straight rows along the Angle of Cuts, then a lap round the wall.
Spiral Cuts
One spiral blending each loop into the next, then a lap round the wall.
Radial Cuts
To be completed. Not built yet.
Cut Direction
Climb runs anticlockwise round the loops (clockwise spindle), Conventional clockwise. Mixed alternates the loops, or zigzags linear rows. Spiral Cuts can't be Mixed.
Angle of Cuts
For Linear Cuts, the rows' direction: 90 runs along the origin's X, 0 along its Y.
Start Point: Inside / Outside
For Offset and Spiral Cuts, start in the middle and work out, or at the wall and work in.
Start Point: Start at Bottom / Start at Top
For Linear Cuts, start the rows at the origin's -Y side or +Y side.
Stepover
How far apart the loops or rows are, as a % of the tool diameter or a distance.

Hole Pocketing tab

How Hole Pocketing cuts round holes with an end mill: a helix down to each level, a spiral out to the wall, and a lap round the wall.

At Top / At Bottom
Whether the picked feature is the hole's top, or its bottom (the top is then the depth above it).
Pick Top
The hole's top is the Z in the box. Pick fills it with a picked item's Z.
Hole Depth
How deep the hole is, down from its top. Pick measures it from a picked item.
Use 3D Model to Detect Depth
To be completed. Not used yet.
Hole Diameter
The hole's diameter, used when Use Arc Dia as Hole Dia is off, and for points.
Use Arc Dia as Hole Dia
Each picked circle or hole face gives its own diameter.
Clean up Pass at each Z Level
Laps the wall a second time at each level.
Cut Direction
Climb turns anticlockwise (clockwise spindle), Conventional clockwise.
Stepover
How far the spiral moves out each turn, as a % of the tool diameter or a distance.
Step Down
The most each level cuts: a % of the tool diameter, a distance, or a Number of Levels.
Helix Dia
The diameter of the helix the tool goes down on.
Helix Pitch: Angle / Height
How steep the helix is: its slope in degrees, or its drop each turn.
Approach Distance
How far above the hole's top the tool comes down to at rapid before the helix starts.

Drilling tab

How Drill drills each hole, in the Features list's order.

Depth
How far to drill. Locate measures it along the origin's Z to a picked point, plane, face or edge.
Add drill tip to depth
Adds the drill's point length, from its diameter and point angle, so the full diameter reaches the depth.
At top / At bottom
Whether the picked feature is the hole's top, or its bottom (the top is then the depth above it).
Dwell
A pause at the bottom of the hole: Off, a Time in seconds, or a number of Revolutions of the spindle.
Approach distance
How far above the hole's top the tool comes down to at rapid before drilling, and returns to between pecks.
Peck depth
How far each peck drills before the drill backs out to clear chips. Leave it blank to drill in one pass.
